# Badge assets

These SVG badges keep the existing Shields layout and embed each logo, so rendering does not depend on the Shields logo catalog.

- Badge layout: [Shields.io](https://shields.io/docs/logos), CC0.
- Vector logos: [SVG Logos](https://github.com/gilbarbara/logos), distributed through [@iconify-json/logos 1.2.10](https://cdn.jsdelivr.net/npm/@iconify-json/logos@1.2.10/icons.json); [collection license](https://github.com/gilbarbara/logos/blob/main/LICENSE.txt).
- AWS CDK and Bedrock artwork: [AWS Icons for PlantUML](https://github.com/awslabs/aws-icons-for-plantuml), [license](https://github.com/awslabs/aws-icons-for-plantuml/blob/main/LICENSE).
- Brand marks remain the property of their respective owners. AWS, OpenAI, and LinkedIn marks use light foregrounds for contrast on the badge background. Oracle uses the O glyph from its wordmark for legibility at badge size.
